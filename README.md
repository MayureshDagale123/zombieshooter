# Zombie Line Defense - Computer Graphics Mini-Project (C++)

A 2D Defense Shooter game developed in C++ using fundamental **Computer Graphics Algorithms**:
- **DDA Line Drawing Algorithm**
- **Bresenham's Line Drawing Algorithm**
- **Bresenham's / Midpoint Circle Drawing Algorithm**
- **2D Transformations (Translation, Rotation around Pivot, Scaling)**
- **Scanline Polygon Fill Algorithm**
- **Boundary Fill & Flood Fill Algorithms**

## Quick Start
1. To compile: Double-click **`build.bat`** (or run `g++ -O2 -std=c++17 main.cpp -o ZombieShooter.exe -lgdi32 -luser32`)
2. To run: Double-click **`run.bat`** (or `ZombieShooter.exe`)

## Controls
- **`[ENTER]` or `[SPACE]`**: Shoot bullet towards zombie
- **`[W]` / `[S]` or `[UP]` / `[DOWN]`**: Move player up and down behind the line
- **`[A]` / `[D]` or `[LEFT]` / `[RIGHT]`**: Aim gun barrel angle
- **`[R]`**: Restart game after Game Over
- **`[ESC]`**: Exit game
